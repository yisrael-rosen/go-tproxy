# Legacy Go Implementation

This directory contains the original Go implementation of the TProxy library.

The project has been migrated to Zig. These files are kept for reference purposes.

## Files

- `tproxy_tcp.go` - Original TCP transparent proxy implementation
- `tproxy_udp.go` - Original UDP transparent proxy implementation
- `tproxy_example.go` - Original example application

For the current Zig implementation, see the `src/` directory.
